## 1. 背景与目标

家长面对多套启蒙动画/儿歌时，常出现「今天播什么」「会不会跳跃太大」「进度记不住」的问题。本产品把已整理好的 7 套核心内容结构化，按**年龄 + 听力基础 + 推荐路径**给出明确导航，并支持绑定**个人已有清晰资源**进行流畅播放与进度记录。

**一句话愿景**

> 按年龄与听力基础，帮家长快速决定「今天该播哪套启蒙内容」，并按推荐顺序推进；播放只走自己的清晰资源，不碰版权灰区。

**成功标准（个人使用）**

- 30 秒内能根据孩子年龄看到「今日建议」
- 路径三阶段一眼看懂，不乱跳
- 系列详情信息完整（特点 / 适龄 / 建议）
- 可绑定并播放自己的资源（本地 / 直链 / **B 站入口优先**），体验清晰流畅
- 进度与收藏本地持久保存

---

## 2. 用户与场景

| 角色 | 诉求 |
|------|------|
| 家长（主用户） | 选片不纠结、路径不乱、进度可记、资源自己可控 |
| 孩子（间接受众） | 不直接操作 App；通过家长选出的内容获得输入 |

**核心场景**

1. 睡前/碎片时间：打开首页 → 今日推荐 → 一键播自己的资源
2. 规划阶段：看启蒙路径 → 确认当前该停在哪一阶
3. 按龄筛选：切换年龄 chips → 只看适龄系列
4. 资源管理：在详情页配置本地文件 / 网盘直链 / **B 站收藏入口**（默认偏好）
5. 复盘：在「我的」看进行中、已完成、收藏

---

## 3. 产品原则

1. **策展优先**：只做精选 7 套，不做全网搜片
2. **路径优先**：推荐顺序高于「随便点播」
3. **个人资源清晰流畅**：播放能力做多源兼容，内容一律来自用户自己维护的清晰资源
4. **零账号**：本地存储，打开即用
5. **版权边界清晰**：产品不提供、不聚合不明片源；只做导航 + 个人资源槽位

---

## 4. 播放能力（重点）

### 4.1 原则

- **不涉及版权分发**：App 内不预置任何视频文件或盗链地址
- **个人资源自备**：用户将自己已合法持有 / 已购买 / 已收藏的清晰资源填入系列资源槽
- **兼容优先**：同一系列可配置多种入口，按优先级尝试播放或跳转

### 4.2 支持的资源类型（兼容矩阵）

| 类型 | 说明 | 交互 |
|------|------|------|
| `local` | 本地视频文件（mp4 / webm 等） | 页内 `<video>` 播放，清晰度取决于源文件 |
| `direct` | 个人网盘 / NAS 直链（可直接拉流的 URL） | 页内播放或新窗口打开 |
| `web` | **默认偏好 B 站**个人收藏/正版入口（亦可手填其他网页） | 外链跳转（不内嵌不明源） |
| `folder` | 本地文件夹路径备忘 | 展示路径提示，方便家长去资源管理器打开 |

### 4.3 体验要求

- 资源列表按「推荐优先级」排序，默认选第一条可播项
- **网页入口默认偏好 B 站**：添加资源时默认选中「B站入口」，占位示例为 `bilibili.com` 收藏/正版页链接（不预置具体 URL）
- 本地/直链：大播放器区域、大按钮、加载状态明确
- 无法页内播放时：明确提示「改为打开外部入口」，一键跳转
- 支持为每个系列维护多条资源（主资源 + 备用）
- 资源编辑仅本地保存，不上传云端

### 4.4 明确不做

- 不爬取、不搜索、不提供第三方不明片源
- 不绕过任何平台会员/DRM
- 不内置「共享资源包」下载

## 8. 数据模型

```ts
type Stage = 'listen' | 'scene' | 'advance';
type ResourceType = 'local' | 'direct' | 'web' | 'folder';
type ProgressStatus = 'todo' | 'doing' | 'done';

interface Series {
  id: string;
  nameZh: string;
  nameEn: string;
  ageMin: number;       // 岁，可用 0 / 1.5 / 2 / 3 / 4
  ageMax: number;       // 可用 99 表示以上
  ageLabel: string;     // 展示用，如 "0-3岁"
  stage: Stage;
  goals: string[];
  features: string[];
  tips: string;
  orderInStage: number;
  accentColor: string;  // 卡片主题色
}

interface ResourceItem {
  id: string;
  seriesId: string;
  type: ResourceType;
  title: string;        // 如「本地高清合集」「B站收藏夹」
  uri: string;          // file 选择后的 object URL / 直链 / 网页 URL / 文件夹备忘
  note?: string;
  priority: number;     // 越小越优先
  createdAt: string;
}

interface Progress {
  seriesId: string;
  status: ProgressStatus;
  favorite: boolean;
  lastWatchedAt?: string;
  note?: string;
}

interface CheckIn {
  id: string;
  date: string;         // YYYY-MM-DD
  seriesId: string;
  minutes?: number;
}
```

**存储**：`localStorage` 键约定

- `enl.ageFilter`
- `enl.progress` → `Record<seriesId, Progress>`
- `enl.resources` → `Record<seriesId, ResourceItem[]>`
- `enl.checkins` → `CheckIn[]`（P1）

## 9. 推荐规则

输入：当前年龄筛选 `age`（或「全部」）

1. 过滤：`ageMin <= age <= ageMax`（「全部」不过滤）
2. 按用户进度：优先推荐该年龄下 `status === 'doing'` 的系列
3. 若无进行中：按阶段顺序 `listen → scene → advance`，取该阶段 `orderInStage` 最小且未 `done` 的 1–2 个
4. 首页展示理由文案：阶段名 + 适龄 + 一句话目标
