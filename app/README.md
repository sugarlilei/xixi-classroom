# 嘻嘻小课堂（正式版 App）

Vite + React + TypeScript + Tailwind + PWA

## 启动

```powershell
cd "D:\aliyun ai\personal\kids-english-enlighten\app"
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。

## 构建

```powershell
npm run build
npm run preview
```

## 功能

- 年龄筛选、今日推荐、三阶段启蒙路径
- 7 套系列详情（特点 / 建议 / 进度 / 收藏）
- 个人资源多源播放：B站入口（默认）/ 本地视频（IndexedDB 持久）/ 直链 / 文件夹备忘
- 本地持久化进度与资源配置；可安装为 PWA
